# Assignment 04: Creating a SKILL for an LLM: Indian Case-Brief Writer

[SKILL.md](SKILL.md) teaches an LLM to write structured, citation-faithful case briefs of Indian Supreme Court and High Court judgments. It works only from the judgment text supplied, separates the *ratio decidendi* from *obiter dicta* and majority from dissent, and never invents a quotation or citation.
