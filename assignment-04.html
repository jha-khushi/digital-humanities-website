Assignment 04

A SKILL for an LLM: Indian Case-Brief Writer

Abstract. A SKILL file is a set of written instructions that turns a general AI assistant into a careful helper for one task. Mine makes an LLM write case briefs of Indian Supreme Court and High Court judgments, especially fundamental-rights cases. It must work only from the judgment it is given, keep the majority separate from the dissent, and never invent a quotation or a citation.

View the repository on GitHub

How the skill works

  1. IdentifyCase name, court, bench and citation, exactly as given.
  2. Separate opinionsMajority, concurring and dissenting.
  3. ExtractFacts, issues as questions of law, both sides’ arguments.
  4. Holding and reasoningWith the articles and tests the court used.
  5. Ratio and obiterWhat binds, what does not, and where the case sits in precedent.
  6. CheckEvery quotation and paragraph number against the judgment.

The brief always has the same sections: Facts · Issues · Arguments · Holding · Reasoning · Ratio decidendi · Obiter dicta · Dissent · Place in doctrine · Key quotations. When several cases are briefed together, it adds a comparison table.

My interpretation

I chose legal briefs because I was reading the privacy cases (Kharak Singh, Govind and R. Rajagopal) for another course, and briefing them by hand is slow. An LLM can do the first draft quickly, but the mistakes that matter most in law are exactly the ones these models make: a citation that does not exist, or a dissent reported as if it were the judgment.

So most of the skill is about what the model must not do. It works only from the text it is given, it says so when something is missing, and it keeps the court’s reasoning apart from any commentary. Writing it was the same lesson as the other assignments, put into instructions: the model is useful only when it is made to stay close to its source.
