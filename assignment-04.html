Assignment 04

A SKILL for an LLM: Indian Case-Brief Writer

Abstract. A SKILL file is a set of written instructions that turns a general AI assistant into a careful helper for one task. Mine makes an LLM write case briefs of Indian Supreme Court and High Court judgments, especially fundamental-rights cases, using only the judgment it is given.

View the repository on GitHub

Method

The skill takes the model through six steps for every judgment:

  1. IdentifyCase name, court, bench and citation, exactly as given.
  2. Separate opinionsMajority, concurring and dissenting.
  3. ExtractFacts, issues and both sides’ arguments.
  4. Holding and reasoningWith the articles and tests the court used.
  5. Ratio and obiterWhat binds, what does not, and where the case sits in precedent.
  6. CheckEvery quotation and paragraph number against the judgment.

Findings

The result is a brief with the same sections every time: Facts, Issues, Arguments, Holding, Reasoning, Ratio decidendi, Obiter dicta, Dissent, Place in doctrine and Key quotations. When several cases are briefed together it adds a comparison table.

Most of the file ended up being rules about what the model must not do: invent a citation, report a dissent as the law, or mix its own opinion into the court’s reasoning.

My interpretation

I chose legal briefs because I was reading the privacy cases (Kharak Singh, Govind and R. Rajagopal) for another course, and briefing them by hand takes a long time. An AI can write a quick first draft, but the mistakes that matter most in law are exactly the ones these models tend to make.

So writing the skill was mostly about keeping the model close to the judgment. It is the same lesson as my other assignments, only written as instructions.

Limitations

  • I tried it only on a few judgments, mostly the privacy cases.
  • It cannot check a citation or a later case that is not in the text it is given.
  • Even with these rules an LLM can make mistakes, so every brief still needs a person to check it against the judgment.
