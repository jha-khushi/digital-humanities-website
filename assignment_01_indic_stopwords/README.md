# Assignment 01: NLP: Indic Stop Words

Stop-word lists for four Indic languages in four scripts. Each file follows the template from the assignment instructions: a header, then the list grouped by grammatical category (conjunctions, pronouns, possessives, postpositions, question words, quantifiers, auxiliary verbs and particles), and a `remove_stopwords()` function.

| File | Language | Script | Family |
|---|---|---|---|
| [hindi_stopwords.py](hindi_stopwords.py) | Hindi | Devanagari | Indo-Aryan |
| [bengali_stopwords.py](bengali_stopwords.py) | Bengali | Bengali | Indo-Aryan |
| [gujarati_stopwords.py](gujarati_stopwords.py) | Gujarati | Gujarati | Indo-Aryan |
| [tamil_stopwords.py](tamil_stopwords.py) | Tamil | Tamil | Dravidian |

```bash
python hindi_stopwords.py      # prints the list size and a before/after example
```

The lists are tested on real text in [dh-05-stopword-evaluation](https://github.com/jha-khushi/dh-05-stopword-evaluation).
